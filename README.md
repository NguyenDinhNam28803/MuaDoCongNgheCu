# MuabanDoCongNghe

Nền tảng quản lý & bán đồ công nghệ (mới + cũ) cho cửa hàng 1–2 người.

- [`client/`](client/) — ứng dụng Next.js full-stack (xem `client/README.md`)
- [`docker-compose.yml`](docker-compose.yml) — PostgreSQL cho dev (`localhost:5434`)
- [`docker/postgres-init/`](docker/postgres-init/) — script chạy khi tạo DB lần đầu (extension `unaccent`, DB test)
